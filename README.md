# Ewann se Graad 4 Leermaat

Afrikaanse iPad-vriendelike leer-app vir Ewann se Graad 4 werk.

Die app het:

- 'n leerpad vir kort opsommings
- flitskaarte
- 'n vasvra
- 'n tydlyn/volgorde-afdeling
- 'n woordelys

Huidige inhoud:

- Kwartaal 1 Geskiedenis nuwe woorde
- Nelson Mandela opsomming
- Apartheid, politieke gevangenes en Robbeneiland
- Mandela se vrylating, 1994-verkiesing en presidentskap

Wanneer daar nuwe opsommings is, werk ons hoofsaaklik `app.js` se data-afdelings by:

- `learningItems`
- `flashcards`
- `quiz`
- `timeline`
- `words`

Maak `index.html` oop, of publiseer die repo met GitHub Pages vanaf die `main` branch.
