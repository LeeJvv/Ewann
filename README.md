# Ewann se Graad 4 Leermaat

Afrikaanse iPad-vriendelike leer-app vir Ewann.

Die app het:

- 'n leerpad vir kort opsommings
- flitskaarte
- 'n vasvra
- 'n tydlyn/volgorde-afdeling
- 'n woordelys

Wanneer daar nuwe opsommings is, werk ons hoofsaaklik `app.js` se data-afdelings by:

- `learningItems`
- `flashcards`
- `quiz`
- `timeline`
- `words`

Maak `index.html` oop, of publiseer die repo met GitHub Pages vanaf die `main` branch.
